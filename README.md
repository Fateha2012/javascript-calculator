# JavaScript Calculator

A calculator built with HTML, CSS and JavaScript for learning.

🔗 **Live demo:** https://fateha2012.github.io/javascript-calculator/

## Features

- Addition, subtraction, multiplication and division
- Clear (AC), sign change (+/-) and percentage buttons
- Decimal support
- Error handling for division by zero
- Mobile-friendly layout

## Built With

- HTML5
- CSS3
- JavaScript

## Run Locally

Open `index.html` in your browser.
